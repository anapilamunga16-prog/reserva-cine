# Reserva de un asiento en sala de cine

**Estudiante:** Ana Pilamunga

## Objetivo

Programa en Python que gestiona la reserva de asientos de una sala de cine pequeña de 3 filas por 4 columnas, representada como una matriz (lista de listas). Permite reservar un asiento indicando su fila y columna, y muestra el estado completo de la sala en formato de tabla usando bucles anidados.

- `0` = asiento libre
- `1` = asiento reservado

## Cómo ejecutarlo

1. Tener instalado Python 3.
2. Ejecutar en la terminal:

```bash
python reserva_cine.py
```

3. Ingresar la fila (0 a 2) y la columna (0 a 3) del asiento que se desea reservar.
4. El programa mostrará en pantalla el estado completo de la sala (3x4) con ceros y unos.
